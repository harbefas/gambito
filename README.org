#+title: Gambito

A keyboard-first chess client for Linux: a Rust daemon and CLI, with independent Quickshell/QML windows.

* Features
- Direct player challenges (create, accept, decline, cancel), private game chat and takeback offers.
- Local two-player games with SAN/UCI input, castling, en passant and a promotion picker.
- Lichess login through the browser (OAuth PKCE), or a personal API token through the CLI.
- Online opponent and computer screens, preset/custom time controls, correspondence, color and AI level selection.
- Ongoing games and the latest 50 finished Lichess games, with ratings and time controls.
- Shared game state across independent windows, server-backed clocks and stream reconnection.
- Move-history navigation, local Stockfish evaluation and Lichess cloud evaluation as a fallback.
- Desktop notifications for game starts, opponent moves, draw offers and results.
- Desktop light/dark theme integration, local game persistence, PGN export and JSON events for scripts.

* Run
Requires Rust 1.95+, Quickshell, Qt Quick Controls and the DejaVu Sans font. Stockfish and =notify-send= enable local evaluation and desktop notifications.

#+begin_src sh
cargo build --release
./target/release/gambito local
./target/release/gambito open
#+end_src

=local= and =open= start the daemon when needed. =gambito daemon= runs it in the foreground. Closing a window leaves the daemon running.

* Lichess
Click *Connect Lichess* or enter =:login= in a window to authorize through your browser. Use the sign-out button or =:logout= to remove the saved token.

Alternatively, create a personal token at https://lichess.org/account/oauth/token/create with =board:play=, =challenge:read= and =challenge:write=, then run:

#+begin_src sh
gambito auth
#+end_src

Paste the token on stdin and finish with Ctrl-D. It is validated and saved with mode 0600 under =$XDG_CONFIG_HOME/gambito/token= (default =~/.config/gambito/token=). Keep tokens out of command-line arguments. For hidden input, pipe the token from a password manager.

The play screen supports opponent searches and Lichess computer challenges. Opponent searches offer Rapid, Classical and Correspondence; Bullet/Blitz tiles are disabled there. The computer tab provides level and color controls. Correspondence and color options are currently available through the UI, not CLI flags.

#+begin_src sh
gambito seek 10 5             # casual by default
gambito seek 15 10 --rated
gambito cancel
gambito ai 1
gambito list
gambito open ABCDef12
gambito move ABCDef12 Nf3
gambito export ABCDef12 > game.pgn
gambito watch                 # continuous NDJSON
gambito --json list
#+end_src

Matched games appear in the list. Open one with =g=, =j/k= and Enter. Windows of the same game share moves; selection, orientation and focus stay independent.

Window commands include =:local=, =:open ID=, =:seek 10 5 casual=, =:cancel=, =:ai 1=, =:resign=, =:draw=, =:confirm=, =:games=, =:window=, =:flip=, =:login=, =:logout=, =:help= and =:quit=.

Moves use English notation: =Nf3=, =O-O=, =e2e4=. Board promotion opens a piece picker. Rewind also works through move-list clicks, mouse scrolling and the navigation buttons. Moves cannot be played while viewing an earlier position.

* Keyboard
Every clickable control has a key; buttons show it. Lobby: =s= find opponent, =c= play computer, =l= sign in/out, =t= TV, =o= openings, =z= puzzles, =p= profile, and on the puzzle card =v= show move, =y= retry, =u= open on the board. Play screen: =m= opponent/computer, =r= rated, =s= side, =1=–=8= computer level, arrows or =hjkl= pick a time control or correspondence days, Enter plays, =c= custom clock with =-= / =+= minutes and =[= / =]= increment. Board: =v= / =u= / =y= puzzle hint, solution and retry, =F= FEN, =L= open on lichess.org, =D= / =R= draw and resign. =?= lists everything.

* Zen mode
On a board, =z= (or the ⤢ button, or =:zen=) hides the side panel and the command bar so only the board shows, handy when tiling windows. =i= or =:= brings the command bar back while typing; =z= or the corner button exits. Keys keep working (engine =e=, rewind =[ ]=, flip =f=).

* Analysis boards
Press =a= or click *Analyse* to create a saved local analysis board from the currently displayed position. This works at the latest move or while rewinding a local or finished online game. Play with the board or SAN/UCI input as usual. The source game and its moves stay unchanged.

To try an alternative, rewind the analysis board and press =a= (*Branch here*) again. Each branch is saved independently and listed under *Saved variations* on its source board. Saved variations appear at the end of the move list; delete one with its ✕ button, with the ✕ in the analysis board's header, with =x= (=:delete=) on the board, or from the game list (✕ on the selected analysis row, or =x=). Deleting asks for confirmation and also removes branches made from that variation. Press =b= or click *Source* to return. Analysis boards also appear in their own *Analysis* section of the game list (between in-progress and finished games, labelled with their source game) and support the existing evaluation, independent windows and PGN export. PGN export contains the selected line; exporting a full variation tree is not implemented.

Use the *FEN* button or =:fen <six-field FEN>= to create an analysis board from a position. =:analyse= and =:source= provide command equivalents. Branching from ongoing online games is blocked in the daemon.

* Lobby
Play tiles, then Lichess TV, the puzzle of the day, games in progress and news. None of these need a Lichess account.

- *Lichess TV*: the featured game with players, titles, ratings and running clocks. The daemon streams it only while a lobby is open (=tv_watch= / =tv_stop= per connection). Click the board to watch that game on Gambito's own board; the *Channels* button, =t= or =:tv= open the TV view: every Lichess channel (Top rated, Bullet, Blitz, Rapid, Classical, UltraBullet, Bot, Computer and the variants) with its current player, a large live board and the players' head-to-head score. =j=/=k= switch channels, =o= or Enter opens the game on Gambito's own board (spectator: no moves; engine and analysis boards work, fair play only restricts your own games) — shown from the side Lichess TV shows. Variant channels are view-only. The daemon streams it through =/api/stream/game/{id}=, which replays every move and then continues live; the game stays watchable to its end, including the result.
- *Puzzle of the day*: click a piece, then its target. Moves are checked against the Lichess solution; the opponent's replies play automatically. *Show move* highlights the piece to move; promotions play the solution's piece. Cached for an hour. *Board* (or =:puzzle=) opens it on the main board like Lichess: the source game's moves first, then your turn. Wrong moves are refused, replies play automatically, and *Hint* (=:hint=), *Solution* (=:solution=) and *Retry* (=:retry=) sit in the puzzle panel. Rating, themes, the engine and analysis boards stay hidden until it is solved. Unsolved puzzles appear under games in progress; solved ones in Profile → Boards.
- *News*: the latest official Lichess posts and community blogs (titles only; thumbnails are WebP, which this Qt build cannot decode). Cached for 30 minutes; click to open in the browser.

* Openings
Press =o= in the lobby (or =:openings=, or the *Openings* button). Walk the opening tree from the Masters or Lichess database (=m= switches; Lichess adds speed and rating filters): the current position with its name, ECO code, game count and white/draw/black results, then its popular continuations as boards with name, move, popularity and results. Arrows or =hjkl= pick a card, Enter plays it, Backspace or =u= goes back, =a= opens the line as an analysis board. *Example games* (=2=) lists Masters top games (opened as analysis boards from their PGN) or recent Lichess games (watched on the board). The explorer requires a connected Lichess account. Lichess's opening descriptions and popularity charts have no API and are not shown.

On the board, *Book* (=m=) shows the explorer for the shown position; click a move to play it (on a finished game it branches an analysis board first).

* Puzzle themes
Press =z= in the lobby (or =:puzzles=, the *Puzzles* button, or *Themes* on the puzzle card). Categories follow Lichess (Recommended, Phases, Motifs, Advanced, Mates, Mate themes, Special moves, Goals, Lengths, Origin, and By opening), each theme with its puzzle count and description. =[= / =]= switch category, arrows or =hjkl= pick a theme, Enter opens the next puzzle of that theme on the board, =d= cycles difficulty. After solving, *Next puzzle* (=n=, =:next=) continues the theme; solved themed puzzles are replaced rather than kept. Puzzles can be deleted like analysis boards.

Signed in, puzzles come from your account and each solved puzzle is reported to Lichess once (=puzzle:write=), so it counts toward your puzzle rating: solved without a mistake is a win, a wrong move or *Solution* is a loss. The panel shows the rating change. Profile → *Puzzles* (=4=) shows your puzzle rating, the dashboard (last 30 days, widening to 90 or 365 when empty), recent results and themes weakest first; Enter practises one. Tokens from before these scopes fall back to anonymous puzzles; sign out and connect again to grant them.

* Profile
Press =p= in the lobby (or =:profile=, or the account button in the bottom bar). The lobby itself only lists games in progress.

- Header: member since, play time, games, wins, draws and losses.
- Rating per speed; select one to see its rating history chart (hover for date and rating) and its stats: peak, lowest, best win, worst loss, win streak, time played.
- *Games* (=1=): full Lichess history, 30 games per page, more load as you scroll. Filter by speed and rated/casual (fetched from Lichess) or result (applied to loaded games). Rows show your accuracy when Lichess analysis exists. Enter or click opens the game.
- *Boards* (=2=): analysis boards and finished local games; =x= deletes an analysis board.
- *Activity* (=3=): recent Lichess activity.

=j=/=k= move the selection, =g= or Esc returns to the lobby. Profile data is fetched only while the profile is open and cached by the daemon for five minutes. Finished Lichess games enter the shared state only when opened, which keeps state updates small.

* Memory
One Quickshell process hosts every window; =gambito open= reuses it over IPC. Views (lobby, board, profile) load only while shown. =gambito open= starts the UI with =QT_QUICK_BACKEND=software=, which saves about 30 MB compared with a GL context; set =QT_QUICK_BACKEND= yourself to override.

* Lichess computer analysis
Finished Lichess games show the server analysis Lichess already has: per-move evaluations, =?!= inaccuracies, =?= mistakes and =??= blunders with the Lichess comment and best line, a played-versus-best bar, and each side's accuracy and error counts. At a judged position the board draws the move actually played (grey) and the better move (green). With the engine on, the local best move is drawn in green too.

Gambito does not compute this itself. Games without analysis show *Load analysis* and a lichess.org link: request computer analysis on the site, then press =r= (or =:lichess=) to fetch it. The Lichess API offers no endpoint to request analysis.

* Evaluation
Install =stockfish= on the daemon's PATH, or set =GAMBITO_STOCKFISH= to an engine executable before starting the daemon. Press =e= to show the evaluation bar, score and principal variation. Scores are from White's perspective. Local evaluation streams score, depth and principal-variation updates while the engine searches. Choose the target with the themed slider or −/+ buttons (1–245, default 30). From the board, use minus to decrease and plus or equals to increase; press =d= or click the depth number to enter =:depth N=. Analysis has no time limit: Stockfish searches to the chosen depth while updating the UI. Raising the target starts a deeper search; changing position or switching the engine off cancels the current search. The green bar shows reached depth relative to the target, not elapsed time or evaluation certainty. Cloud results have a fixed depth and cannot be deepened without a local engine. Cached and cloud results appear immediately without an artificial progress animation.

When no local engine is available, Gambito tries the Lichess cloud cache. Missing engines are checked again on evaluation requests after a five-second cooldown. Cloud results expire after five seconds so revisiting an evaluated position can detect a newly installed engine without restarting the daemon. Toggle evaluation again or navigate to request a new evaluation.

Evaluation is blocked by the daemon during ongoing online games, including when viewing earlier moves. Local games and finished online games support evaluation.

* Theme
The UI reads =~/.local/state/desktop/theme= and =~/.config/desktop/theme-<mode>.toml=, follows changes live and uses its own fallback palette when these files are unavailable.

* Protocol and paths
The default socket is =$XDG_RUNTIME_DIR/gambito/socket=. Each line is a UTF-8 JSON object. On connection, clients receive =type: state= with game state; updates produce new snapshots. Command responses have =type: reply=, the original =request_id=, =ok= and either =data= or =error=. Operational events use =type: notice=.

#+begin_src json
{"cmd":"move","game":"ABCDef12","notation":"e4","request_id":"42"}
#+end_src

Evaluation requests accept ="depth": 30= (an integer from 1 to 245) and can include ="stream": true= to receive =type: eval= events with the same =request_id= before the final reply. Each event contains =eval= with the game ID (=for=), ply, score, depth, target depth and principal variation. =cancel_eval= stops that connection's current analysis, and a new =eval= request supersedes it. Updates go only to the requesting connection; clients should discard updates for superseded requests.

=GAMBITO_SOCKET= selects another socket (its directory must be mode 0700). =GAMBITO_UI= selects the QML directory. =GAMBITO_API_URL= permits a loopback API for integration tests. The daemon does not execute shell commands from the protocol.

* User installation
Install =packaging/gambito.service= in =~/.config/systemd/user/=, the executable in =~/.local/bin/gambito=, and all =ui/*.qml= files in =~/.local/share/gambito/ui/=. Enable with =systemctl --user enable --now gambito.service=. Restart the service after updating the executable.

cargo build
python3 tests/integration.py

python3 tests/engine-depth.py
shellcheck tests/fake-stockfish.sh

Build before running the Python tests: =cargo test= alone does not update the daemon executable they use. Integration tests use a fake HTTP server and UCI engine, including recovery after installing an engine while the daemon is running. UI tests use offscreen Quickshell and report captured output on assertion failures. Tests do not challenge or play against real accounts.

* Current limitations
- Standard chess only; no studies, opening explorer, puzzles, premoves or chat yet.
- Rewind is read-only; use Analyse / Branch here to play alternatives on a separate saved board.
- Local games are human versus human without clocks; computer opponents use Lichess.
- Local draws can be agreed with =:draw=; no dedicated threefold/50-move claim UI.
- Online moves require server confirmation; timed-out moves are not automatically replayed.
- History is limited to the latest 50 finished Lichess games.
- No shortcut/theme editor. The interface runs independently of the desktop shell.
- Remote integration is tested against a simulated server; real-account play requires user authentication.

* Challenges, chat and takebacks
Press =C= or click *Challenges* to invite a player or handle pending invitations. The screen offers standard chess at Blitz, Rapid, Classical and correspondence time controls, casual/rated and color selection. Bullet and variants are unsupported by this client. Real-time invitations expire after 20 seconds; send a new invitation if needed. Pending invitations refresh after an account-stream reconnect. Existing accounts must sign out and connect again to grant =challenge:read=.

On the challenges screen: =u= focuses the username, =t= cycles time controls, =c= cycles colors, =v= toggles rated, =s= sends, =j/k= selects an invitation, =a= accepts, =x= declines/cancels, and =r= refreshes. Enter in the username field also sends. The command form =:challenge USER MIN INC [rated]= supports custom clocks; =:accept ID=, =:decline ID= and =:cancelchallenge ID= respond to a specific invitation.

In your Lichess game, =c= switches between the move list and private player chat. Enter sends and Esc returns keyboard focus to the board. Failed sends preserve the draft. Opening the chat fetches its history; new player messages arrive on the game stream. The panel retains the latest 100 messages and messages are displayed as plain text. =:chat MESSAGE= sends directly.

=T= requests a takeback or accepts the opponent's offer; =Y= declines. The board changes only when Lichess sends the resulting game state. These controls are available only for your live online games. =:takeback= and =:takeback no= are equivalent commands.

#+begin_src sh
gambito challenges
gambito challenge Friend --minutes 3 --increment 2 --color random
gambito challenge Friend --days 3 --rated
gambito accept CHALLENGE_ID
gambito decline CHALLENGE_ID
gambito cancel-challenge CHALLENGE_ID
gambito chat GAME_ID
gambito chat GAME_ID "Good game!"
gambito takeback GAME_ID
gambito takeback GAME_ID --decline
#+end_src
